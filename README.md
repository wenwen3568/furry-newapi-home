# furry-newapi-home

给 New API 换一个不会让人一眼划走的首页。

网上大多数 New API 站点的首页都是默认那套，看多了难免审美疲劳，所以我给自己搭了现在这一版：完整的 New API 默认首页内容，加上一张随机会动的福瑞背景图，访客每次进来看到的都是不同的画面。

## 为什么有这个仓库

- 想让首页有点自己的风格，又不想大改 New API 本身
- 背景图来自公开的福瑞图片接口，每次刷新随机换一张，加载失败也有本地兜底图，不会白屏
- 整站打包成一个 `index.html`，拷走就能用，不需要任何构建工具

## 使用方法

1. 把 `index.html` 托管到任意静态服务（GitHub Pages、对象存储、自己的服务器都行）
2. 打开 New API 后台 → 系统设置 → 系统信息 → 首页内容
3. 填入你的页面地址，例如 `https://你的用户名.github.io/furry-newapi-home/`
4. 保存，刷新首页即可。想换回默认首页时，清空那个字段就行

## 背景图接口

背景图来自 [api.furry.ist](https://api.furry.ist/furry-img/)，每次请求返回一张随机福瑞图片。页面内建了重试逻辑，接口偶尔抽风时会自动多试几次，全部失败则回退到内嵌的本地壁纸。

## 说明

- 单文件，无外部依赖，CSS / 字体 / 图标 / 兜底壁纸全部内联
- 自适应深浅色模式，背景淡入做了平滑处理，不会突兀
- 页脚留了一句「本公益站由两只福瑞运营」，不需要可以自行删掉

用 New API 的可以随意拿去改，改完记得顺手把福瑞那行也改了（或者保留，随你）。
